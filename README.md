# 🛠️ Toolkit de Suporte N1 & Infraestrutura

Conjunto de scripts e utilitários em **PowerShell** desenvolvidos para agilizar diagnósticos, padronizar coletas de dados e automatizar tarefas rotineiras de atendimento técnico e infraestrutura.

---

## 🎯 Objetivo

Reduzir o tempo médio de atendimento (TMT) e padronizar o diagnóstico inicial de estações Windows antes do escalonamento de chamados complexos, garantindo dados precisos de rede, hardware e sistema operacional.
